## 시작하기

### 봇 찾기 및 시작

1. **텔레그램 앱 열기**
   - 모바일 또는 데스크톱 텔레그램 앱을 엽니다.

2. **봇 검색**
   - 검색창에 `@YourPrismInsightBot` 입력
   - 또는 제공된 링크를 클릭

3. **대화 시작**
   - `/start` 명령어를 입력하여 봇과 대화 시작

4. **채널 구독 확인**
   - 봇은 채널 구독자만 사용할 수 있습니다
   - 필요한 경우 안내되는 채널에 가입하세요

### 첫 사용

```
사용자: /start

봇: 안녕하세요! PRISM-INSIGHT AI 봇입니다 👋

저는 주식 투자에 대한 개인화된 조언을 제공합니다.

사용 가능한 명령어:
• /evaluate - 보유 종목 평가 및 조언
• /report - 종목 상세 분석 보고서
• /history - 종목 분석 히스토리
• /help - 도움말

어떤 서비스를 이용하시겠어요?
```

## 주요 기능

### 1. 개인화된 종목 평가 (`/evaluate`)

**특징**:
- 보유 종목에 대한 맞춤형 평가
- 평균 매수가 기반 손익 분석
- 보유 기간 고려한 전략 제안
- 원하는 톤으로 피드백 제공

**제공 정보**:
- 현재 주가 분석
- 손익률 계산
- 기술적 분석
- 앞으로의 전망
- 매도/보유 타이밍 조언

### 2. 종목 상세 분석 (`/report`)

**특징**:
- 종목에 대한 심층 분석 보고서
- Markdown 및 HTML 형식 제공
- 24시간 캐시 (빠른 재조회)

**포함 내용**:
- 기업 개요
- 재무 분석
- 기술적 분석
- 뉴스 및 이슈
- 투자 의견

### 3. 대화형 후속 질문

**특징**:
- 24시간 대화 컨텍스트 유지
- 이전 대화 기억
- 자연스러운 후속 질문 가능

**예시**:
```
사용자: 언제 팔면 좋을까요?
봇: [이전 맥락을 고려한 답변]

사용자: 추가 매수는 어때요?
봇: [대화 맥락을 이어서 답변]
```

## 명령어 사용법

### `/evaluate` - 종목 평가

개인화된 종목 평가 및 조언을 받습니다.

#### 사용 절차

**1단계: 명령어 입력**
```
사용자: /evaluate
```

**2단계: 종목 입력**
```
봇: 평가받고 싶은 종목 코드 또는 이름을 입력하세요.

예시:
- 005930 (종목 코드)
- 삼성전자 (종목 이름)

사용자: 삼성전자
```

**3단계: 평균 매수가 입력**
```
봇: 평균 매수가를 입력하세요. (원 단위)

예시: 70000

사용자: 70000
```

**4단계: 보유 기간 입력**
```
봇: 보유 기간을 입력하세요. (개월 단위)

예시:
- 3개월
- 6개월
- 1년 (12개월)

사용자: 6
```

**5단계: 피드백 스타일 선택**
```
봇: 어떤 스타일의 피드백을 원하시나요?

예시:
- 친구같이 (편안하고 친근한 톤)
- 전문가처럼 (전문적이고 정확한 톤)
- 간결하게 (핵심만 간단히)

사용자: 친구같이
```

**6단계: 매매 배경 입력 (선택사항)**
```
봇: 매매 배경이나 투자 히스토리를 알려주세요. (선택사항)
건너뛰려면 '없음'을 입력하세요.

예시:
- 단기 스윙 매매
- 장기 투자 목적
- 분할 매수 진행 중

사용자: 단기 스윙 매매
```

**7단계: AI 분석 결과**
```
봇: 🤖 AI 분석 중...

[잠시 후]

📊 삼성전자 (005930) 평가 결과

안녕! 삼성전자 분석해봤어 😊

**현재 상황**
- 현재가: 72,500원
- 매수가: 70,000원
- 수익률: +3.57%

**분석**
6개월 단기 스윙으로 보유 중이시군요! 현재 약 3.5% 수익 중인데,
삼성전자가 최근 반도체 업황 회복 기대감으로 상승세를 타고 있어요.

[... 더 자세한 분석 ...]

**조언**
단기 스윙이라면 5% 수익 구간에서 일부 차익 실현을 고려해보는 게
어떨까요? 70,000원 부근에 지지선이 있으니 분할 매도 전략도 좋을 것 같아요!

궁금한 점 있으면 언제든 물어봐요! 👍
```

#### 후속 질문 예시

평가를 받은 후 24시간 내에 후속 질문을 할 수 있습니다:

```
사용자: 언제 팔면 좋을까요?

봇: 앞서 말씀드린 것처럼, 삼성전자는 현재 상승 추세라
5% 수익 구간(73,500원)에서 절반 정도 차익 실현하고,
나머지는 75,000원 목표가까지 보유하는 게 좋을 것 같아요.

---

사용자: 추가 매수는 어때요?

봇: 단기 스윙 전략이시라면 지금 추가 매수보다는
현재 포지션 관리에 집중하시는 게 나을 것 같아요.
만약 조정이 와서 68,000원 아래로 내려간다면
그때 추가 매수를 고려해보세요!
```

### `/report` - 종목 분석 보고서

특정 종목에 대한 심층 분석 보고서를 받습니다.

#### 사용 절차

**1단계: 명령어 입력**
```
사용자: /report
```

**2단계: 종목 입력**
```
봇: 분석 보고서를 받고 싶은 종목 코드 또는 이름을 입력하세요.

사용자: 카카오
```

**3단계: 보고서 생성**
```
봇: 🤖 카카오 (035720) 분석 보고서 생성 중...

[1-2분 후]

✅ 보고서 생성 완료!

📄 카카오_20251111_analysis.md (Markdown)
📑 카카오_20251111_analysis.html (HTML)

파일을 다운로드하여 확인하세요!
```

#### 보고서 내용

Markdown 및 HTML 파일에는 다음 내용이 포함됩니다:

```markdown
# 카카오 (035720) 종합 분석 보고서

## 1. 기업 개요
- 사업 영역
- 주요 제품/서비스
- 시장 점유율

## 2. 재무 분석
- 매출/영업이익 추이
- 재무 비율 (PER, PBR, ROE)
- 부채 비율

## 3. 기술적 분석
- 차트 패턴
- 이동평균선 분석
- 거래량 분석

## 4. 뉴스 및 이슈
- 최근 주요 뉴스
- 산업 트렌드
- 규제 이슈

## 5. 투자 의견
- 목표 주가
- 투자 등급
- 리스크 요인
```

#### 캐시 활용

보고서는 24시간 동안 캐시됩니다:

```
사용자: /report
사용자: 카카오

봇: 📋 24시간 이내 생성된 보고서가 있습니다.
최신 보고서를 보내드릴까요, 아니면 새로 생성할까요?

1️⃣ 최신 보고서 보내기
2️⃣ 새로 생성하기

사용자: 1

봇: ✅ 최신 보고서를 보내드립니다!
[파일 전송]
```

```

```

**2단계: 종목 입력**
```

```

## 대화형 평가

### 대화 컨텍스트

`/evaluate` 명령으로 평가를 받은 후, **24시간** 동안 후속 질문을 할 수 있습니다.

#### 작동 방식

```
[시간: 10:00]
사용자: /evaluate
→ 삼성전자 평가 완료

[시간: 10:05]
사용자: 언제 팔면 좋을까요?
→ 봇이 이전 맥락을 기억하고 답변

[시간: 14:30]
사용자: 배당은 언제 받나요?
→ 여전히 삼성전자 관련 대화로 이어짐

[시간: 다음날 10:01 (24시간 경과)]
사용자: 추가 매수는?
→ 새로운 /evaluate가 필요합니다
```

### 대화 예시

#### 예시 1: 매도 타이밍

```
사용자: /evaluate
[삼성전자 평가 완료]

사용자: 언제 팔면 좋을까요?

봇: 현재 3.5% 수익 중이시고 단기 스윙 전략이시니,
다음 두 가지 시나리오를 고려해보세요:

1️⃣ 보수적 전략: 5% 수익(73,500원)에서 절반 매도
2️⃣ 공격적 전략: 10% 목표(77,000원)까지 보유

저는 1번을 추천드려요. 수익을 확정하면서도
상승 여력을 남겨두는 전략이거든요!
```

#### 예시 2: 리스크 관리

```
사용자: 위험 요소는 뭐가 있나요?

봇: 삼성전자의 주요 리스크는:

⚠️ 단기 리스크:
- 반도체 업황 변동성
- 환율 영향 (원화 강세 시 불리)

⚠️ 중기 리스크:
- 중국 경기 둔화
- 경쟁사 추격 (TSMC, SK하이닉스)

대응 방법:
- 손절가 설정 (68,000원)
- 분할 매도로 리스크 분산
```

#### 예시 3: 추가 매수

```
사용자: 추가 매수하려면 언제가 좋을까요?

봇: 단기 스윙 전략이라면 지금보다는 조정 시
추가 매수가 유리해요.

추천 매수 구간:
1️⃣ 68,000원 (1차 지지선)
2️⃣ 65,000원 (2차 지지선)

현재가 근처에서 추가 매수하시려면
장기 투자 전략으로 전환을 고려해보세요!
```

## 자주 묻는 질문

### Q1. 봇이 응답하지 않아요

**A**: 다음을 확인하세요:
1. 채널 구독 여부
2. 네트워크 연결
3. 봇 서버 상태 (일시적 장애 가능)

5분 정도 기다린 후 다시 시도해보세요.

### Q2. 종목 코드를 모르겠어요

**A**: 종목 이름을 한글로 입력하세요:
```
✅ 삼성전자
✅ 카카오
✅ NAVER
✅ SK하이닉스
```

### Q3. 대화 컨텍스트가 사라졌어요

**A**: 대화 컨텍스트는 **24시간** 동안만 유지됩니다.
- 24시간 후에는 새로운 `/evaluate`가 필요해요
- 컨텍스트를 연장하려면 중간에 메시지를 보내세요

### Q4. 보고서를 다시 받고 싶어요

**A**: `/report` 명령을 다시 사용하세요:
- 24시간 이내: 캐시된 보고서 전송 (빠름)
- 24시간 이후: 새로운 보고서 생성 (1-2분 소요)

### Q5. 여러 종목을 동시에 물어볼 수 있나요?

**A**: 한 번에 하나의 종목만 평가 가능합니다:
```
❌ "삼성전자와 카카오 비교해줘"
✅ /evaluate → 삼성전자
✅ /evaluate → 카카오 (별도로)
```

### Q6. 실시간 주가 정보를 제공하나요?

**A**: 네, AI가 실시간 주가 정보를 조회하여 분석에 활용합니다.
하지만 극단적인 급등락 상황에서는 약간의 지연이 있을 수 있습니다.

### Q7. 투자 조언을 100% 믿어도 되나요?

**A**: ⚠️ **면책 조항**:
- AI 봇의 조언은 참고용입니다
- 최종 투자 결정은 본인의 판단으로 하세요
- 투자로 인한 손실은 본인 책임입니다
- 과거 실적이 미래 수익을 보장하지 않습니다

### Q8. 해외 주식도 분석 가능한가요?

**A**: 현재는 **국내 주식**만 지원합니다:
- ✅ KOSPI (코스피)
- ✅ KOSDAQ (코스닥)
- ❌ 미국 주식 (추후 지원 예정)
- ❌ 중국/일본 주식

## 문제 해결

### 봇이 응답하지 않을 때

**1단계: 기본 확인**
```
- [ ] 채널 구독 여부 확인
- [ ] 인터넷 연결 확인
- [ ] 텔레그램 앱 최신 버전 확인
```

**2단계: 재시도**
```
1. 대화 종료 → 다시 시작
2. /start 명령 재입력
3. 봇 차단 해제 후 재시작
```

**3단계: 관리자 문의**
```
위 방법으로 해결되지 않으면
@관리자계정으로 문의하세요.

필요 정보:
- 사용자 ID
- 오류 발생 시간
- 입력한 명령어
- 오류 메시지 스크린샷
```

### 잘못된 종목 정보가 나올 때

**원인**:
- 종목 코드/이름 오타
- 상장폐지된 종목
- 봇이 인식하지 못하는 종목

**해결**:
```
1. 정확한 종목 코드 확인 (네이버 금융 등)
2. 종목 이름을 정확히 입력
3. 6자리 종목 코드 사용
```

### 보고서 다운로드 실패

**원인**:
- 파일 크기 초과
- 네트워크 불안정

**해결**:
```
1. Wi-Fi 연결 확인
2. 텔레그램 저장 공간 확인
3. 잠시 후 다시 시도
```
